⚡ Quick Answer: Where Can I Use Risk Reports?

The risk reports dashboard (risk-assessment-viewer.html) can be accessed from 4 main locations:

1️⃣ Underwriter Dashboard

Location: /underwriter-dashboard.html

How: Click "Risk Report" button on applications

URL: ?id=<application_id>

2️⃣ Admin Dashboard

Location: /admin.html

How: "Risk Assessment Reports" section or "Risk Report" button

URL: ?id=<underwriting_id>

3️⃣ Claims Adjuster Dashboard

Location: /claims-adjuster-dashboard.html

How: Click "Risk Report" button on claims

URL: ?customer_id=<customer_id>

4️⃣ Actuary Dashboard

Location: /actuary-dashboard.html

How: Direct URL or API access

URL: Direct URL access or API calls

💡 Direct Access URLs

You can also access reports directly via URL:

  • /risk-assessment-viewer.html?id=UW-001 (by application ID)
  • /risk-assessment-viewer.html?customer_id=CUST-001 (by customer ID)
  • /risk-assessment-viewer.html?email=user@example.com (by email)

JavaScript Integration

// Link to risk report from your dashboard
function viewRiskReport(applicationId) {
    window.location.href = `/risk-assessment-viewer.html?id=${encodeURIComponent(applicationId)}`;
}

function viewCustomerRiskReport(customerId) {
    window.location.href = `/risk-assessment-viewer.html?customer_id=${encodeURIComponent(customerId)}`;
}
