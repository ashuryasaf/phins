Annuity Reserves Forecast

This tool sizes the reserve required to back the platform's 4% + CPI guaranteed annuity on customer savings, year by year, and ties the forecast back to a portfolio simulation. Use it to compare future annuity payments (per converting customer) against present monthly deposits, and to surface the top-up reserve when realised market returns underperform the guarantee.
Formula — P(X) (annuity guarantee top-up reserve)

P(X) = max(0, G(F(X);X) − G(g;X) + Σ_{y=0..N−1} G(g;y) × (1 + madad(y)) + ( expec_ret(y+1)(g) − expec_ret(y+1)(I) ) + Σ_{y=0..N−1} ( arad_loss(expec_ret(y+1)(g) − I(y+1)) − arad_loss(expec_ret(y+1)(I) − I(y+1)) ) × I(y+1) × (1 + I(y+1)) × (1 + madad(y+1)) − I(y+1) × (1 + madad(y+1)) × (1 + I(y+1)) )

g = guarantee rate (default 4%) · F(X) = realised market return · expec_ret = expected market return curve · I = guarantee credit · madad = CPI · arad_loss(x) = λ · max(0, −x)² (one-sided quadratic loss)
Inputs
Set lower than expected to stress-test the reserve.
Weight on G(F;X)−G(g;X)
Weight on madad/inflation term
Weight on arad_loss term
Weight on credited interest deduction
Months of future annuity payments to reserve for (e.g. 60)

    Annual Regulatory Report Pipeline: not bound

    First-class annual filing. This bar produces a single, jurisdiction-aware annual report that public insurance issuers in the United States (SEC 10-K + NAIC statutory), Canada (OSFI MCT/LICAT + CSA AIF on SEDAR+), and Israel (ISA prospectus + CMISA Solvency II + IFRS 17) file with their regulators and stock-exchange chamber. Every figure is sourced deterministically from the Simulation bars (portfolio simulator + sandbox lifecycle + reserves + valuation) so the pipeline stays the single source of truth — no figures are invented in this section.
