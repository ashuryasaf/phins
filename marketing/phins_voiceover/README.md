# Phins — Bilingual Voice-Over Package ("The Woman I'll Become")

High-end AI-video voice-over script for Phins, written from the perspective of a
35-year-old woman reflecting on aging and the risk of one day needing total
health care. Fully bilingual (English + Hebrew) and tuned for **ElevenLabs**.

## Files

| File | Description |
|---|---|
| `Phins_VoiceOver_Script_EN_HE.docx` | Editable Word document (formatted, RTL Hebrew). |
| `Phins_VoiceOver_Script_EN_HE.pdf` | Print/share-ready PDF (same content). |

## What's inside

1. ElevenLabs voice-over setup (voice profile + settings table for EN/HE, audio-tag notes).
2. Shot-by-shot — English master (9 shots, exact camera/lighting directions + VO).
3. Shot-by-shot — Hebrew master (right-to-left, feminine verb forms).
4. Clean continuous VO (EN + HE) — paste straight into ElevenLabs.
5. ElevenLabs v3 audio-tag version (optional, more expressive).
6. 30-second cutdown (EN + HE).
7. 9:16 vertical social cutdown (~30s) with reframing notes and shot list.
8. Production notes (music, subtitles, taglines, word counts).
