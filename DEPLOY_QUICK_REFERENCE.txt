╔══════════════════════════════════════════════════════════════════════════╗
║                        FASTEST WAY TO DEPLOY                             ║
╚══════════════════════════════════════════════════════════════════════════╝

  1. Go to: https://railway.app
  2. Click: "Login with GitHub"
  3. Click: "New Project" → "Deploy from GitHub repo"
  4. Select: ashuryasaf/phins
  5. Wait 2-5 minutes for build
  6. Done! ✅

  Your site: https://[project-name].up.railway.app

╔══════════════════════════════════════════════════════════════════════════╗
║                        RAILWAY CLI COMMANDS                              ║
╚══════════════════════════════════════════════════════════════════════════╝

  # Install CLI
  npm install -g @railway/cli
  # or
  brew install railway

  # Deploy
  railway login
  railway init
  railway up

  # Monitor
  railway logs
  railway logs --follow

  # Get URL
  railway domain

  # Open in browser
  railway open


╔══════════════════════════════════════════════════════════════════════════╗
║                    CUSTOM DOMAIN (www.phins.ai)                          ║
╚══════════════════════════════════════════════════════════════════════════╝

  Railway Dashboard:
    Settings → Domains → Custom Domain → Enter: www.phins.ai
    Copy the CNAME target

  Your DNS Provider:
    Type:   CNAME
    Name:   www
    Target: [your-railway-url].up.railway.app
    TTL:    3600

  Wait: 5-30 minutes for DNS propagation
  SSL:  Automatic (15 minutes after DNS)
